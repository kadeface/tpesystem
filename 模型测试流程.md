# 测试增值评价模型的方法

## 1. 使用管理命令测试

我们已经创建了`evaluate_tes.py`管理命令，这是最直接的测试方法：

```bash
# 基本测试 - 指定学期和学科
python manage.py evaluate_tes --base-semester 2023-2024-1 --current-semester 2023-2024-2 --subject CHN --no-save

# 指定具体考试进行比较
python manage.py evaluate_tes --base-semester 2023-2024-1 --current-semester 2023-2024-2 --subject CHN --base-exam 202310-FINAL --current-exam 202320-FINAL
python manage.py evaluate_tes --base-semester 2022-2023-1 --current-semester 2022-2023-2 --subject CHN --base-exam 2025-DIST-M-202301 --current-exam 2025-DIST-M-202307
# 通过考试类型自动选择考试
python manage.py evaluate_tes --base-semester 2023-2024-1 --current-semester 2023-2024-2 --subject CHN --exam-type FINAL

# 使用配置
python manage.py evaluate_tes --base-semester 2023-2024-1 --current-semester 2023-2024-2 --subject CHN --config TES_CHN_01
```

            'raw_score': [85, 75, 80]

## 4. 创建测试视图

如果您希望在Web界面中测试，可以创建一个简单的测试视图：

```python:core/views.py
from django.http import JsonResponse
from django.views.decorators.http import require_POST
from django.views.decorators.csrf import csrf_exempt
import json
from core.algorithms.evaluation_service import EvaluationService

@csrf_exempt
@require_POST
def test_value_added(request):
    """测试增值评价API"""
    try:
        data = json.loads(request.body)
        
        base_semester = data.get('base_semester')
        current_semester = data.get('current_semester')
        subject_id = data.get('subject_id')
        base_exam_id = data.get('base_exam_id')
        current_exam_id = data.get('current_exam_id')
        score_fields = data.get('score_fields', ['raw_score'])
        
        if not all([base_semester, current_semester, subject_id]):
            return JsonResponse({'error': '缺少必要参数'}, status=400)
        
        service = EvaluationService()
        results = service.evaluate_with_tes(
            base_semester,
            current_semester,
            subject_id,
            base_exam_id=base_exam_id,
            current_exam_id=current_exam_id,
            score_fields=score_fields,
            save=False
        )
        
        # 转换结果为可JSON化的格式
        stats = {
            'count': len(results),
            'mean': float(results['value_added'].mean()),
            'max': float(results['value_added'].max()),
            'min': float(results['value_added'].min())
        }
        
        # 取前10条数据作为样本
        samples = []
        for _, row in results.head(10).iterrows():
            sample = {
                'student_id': row['student_id'],
                'value_added': float(row['value_added']),
                'rank': int(row.get('value_added_rank', 0))
            }
            samples.append(sample)
        
        return JsonResponse({
            'success': True,
            'stats': stats,
            'samples': samples
        })
    
    except Exception as e:
        return JsonResponse({'error': str(e)}, status=500)
```

## 5. 数据验证

无论使用哪种测试方法，都应该验证以下几点：

1. **数据一致性**: 基线和当前分数的学生集合是否匹配
2. **计算准确性**: 简单差值模式下，value_added 应该等于 current_score - base_score
3. **排名一致性**: 如果使用TES模式，验证排名是否与原始分数排序一致
4. **特殊值处理**: 测试缺失值、极端值的处理
5. **增值分布**: 检查增值分布是否合理，如均值是否接近0，标准差是否合理

## 小结

建议先使用管理命令进行快速测试，然后进入Django shell进行交互式探索，最后编写单元测试确保后续修改不会破坏功能。对于生产环境，确保使用真实数据的子集进行测试，验证模型在实际数据上的表现。
