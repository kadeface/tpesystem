# 数据仓库 4.0

数据仓库设计，包含以下核心维度的表结构。这些表通过外键关联，确保数据的完整性和一致性。

1. **基础维度**：
   - 区域表 (Region)
   - 学年学期表 (Semester)

2. **学生维度**：
   - 学生表 (Student)
   - 家庭表 (Family)
   - 学生历史记录表 (StudentHistory)

3. **教师维度**：
   - 教师表 (Teacher)
   - 教师-学科关联表 (TeacherSubject)
   - 教师历史记录表 (TeacherHistory)
   - 教师团队表 (TeacherTeam)

4. **学校维度**：
   - 学校表 (School)
   - 年级表 (Grade)
   - 班级表 (Class)

5. **学科维度**：
   - 学科表 (Subject)
   - 学科分值表 (SubjectScore)
   - 学科关联表 (SubjectRelation)

6. **考试与成绩维度**：
   - 考试表 (Exam)
   - 成绩表 (Score)

7. **评价维度**：
   - 评价指标表 (EvaluationMetrics)
   - 增值评价表 (ValueAddedEvaluation)
   - 统计分析表 (StatisticalAnalysis)
