⚠️ 学期升级提示

导入新学期成绩数据前，请确认是否已完成上一学期的升级操作。未进行升级可能导致：

  • 班级年级关联错误
  • 学生历史记录缺失
  • 教师任课关系混乱

建议先执行以下升级命令：

python manage.py promote_students --from-semester=[上一学期ID] --to-semester=[当前学期ID]
python manage.py promote_teachers --from-semester=[上一学期ID] --to-semester=[当前学期ID]
